# Monthly Branding Assets

This folder is set up for month-based branding swaps.

## Folders

- `icons/` for the small top-left brand icon
- `hero/` for the larger top-right hero image

## File naming

Use the month-number prefix so the files sort naturally:

- `01-january.png`
- `02-february.png`
- `03-march.png`
- `04-april.png`
- `05-may.png`
- `06-june.png`
- `07-july.png`
- `08-august.png`
- `09-september.png`
- `10-october.png`
- `11-november.png`
- `12-december.png`

The site currently expects PNG files for both icons and hero images.

Recommended sizes:

- Icons: square, around `256x256`
- Hero images: square or portrait-friendly transparent art, at least `960px` wide
